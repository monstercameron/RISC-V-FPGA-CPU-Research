# Upstream license copies

These notices apply to bundled third-party material, as mapped in [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md). They are separate from the project's original-work MIT license.

The license texts are preserved as received. [provenance.json](provenance.json) records immutable origins and SHA256 identities, including the existing PicoRV32 COPYING file. Do not place these extra files inside `reference-sources/`, whose allowed inventory is locked.
