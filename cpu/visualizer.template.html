    Simulator connection and evidence

    This is a replay of actual RTL simulation clocks. Circuit blocks show the state and inputs sampled just before each rising edge; registers and memory show the effects after that edge. The RAM adapter writes on acceptance, then the CPU receives acknowledgement on the following clock. The picture groups the functional blocks; it is not a placed FPGA netlist.

    In the connected view, Run simulation launches LLVM and Icarus, checks every event, and loads the new capture. Playback does not rerun the CPU. No FPGA board or full RVA23 implementation is implied.
