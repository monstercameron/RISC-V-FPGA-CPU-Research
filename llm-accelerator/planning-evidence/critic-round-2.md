## Remaining actionable findings

1. **C09 / High — reset makes region epoch ownership stale.** `abi-v1.md:56` increments context epoch, while `:86` requires matching epoch ownership on mutable regions. Their ownership remains stamped by the old registration (`:74-86`), referenced regions cannot unregister (`:28`), and state/workspace handles must match registration (`:57`). Define an atomic successful-reset rebind of all owned mutable registrations, or a legal teardown/re-registration protocol. Failed reset must not leave a partly rebound context. Require evaluate -> reset -> evaluate and fault -> drain -> reset -> evaluate tests, including stale old-epoch access and wrap.

2. **C10 / High — no executable host weight-service/bootstrap transport contract.** `abi-v1.md:84` delegates MODEL_BYTES to a checked host range service, but the register map (`:13-24`) has no request/response/release path for that service, no source-to-staging binding, and no defined data upload/initial table population operation. Capability session nonce is read-only yet must be written at attach (`:60`, `:112`) with no bootstrap interface. Specify a versioned adapter sub-contract with concrete mailboxes/queues, fields, ownership and completion rules: session initialization; initial DDR table/input upload; tagged immutable byte requests; registered source/staging ranges; generation/epoch; host fill acknowledgement; tile consumption/release; bounded credits; error/cancel. The graph sequencer must remain on-core. Require a complete simulated boot/register/evaluate trace that crosses two staging windows, a >4-GiB model offset, an SG boundary and a canceled request. The board-specific implementation can remain pending, but its required interface cannot remain an unnamed service.

3. **C11 / Medium — INPUT indirection and media multiplicity are not independently decodable.** `abi-v1.md:104` gives a descriptor-table pointer but does not say whether it points to a 128-byte tensor descriptor or raw payload, what kind owns these input descriptors, or how entry alignment/count is validated. The table-kind list (`:92-98`) has no general input-tensor-descriptor arena. The same line requires one pixel role per media item, while `:106` defines command media count as runs and pixel roles as distinct pixel items. Define pointer types for each role, a legal descriptor-table/arena schema and element-count semantics; consistently separate run_count from pixel_item_count. Require one fully valid EVALUATE fixture, including four video runs sharing one pixel descriptor, plus malformed descriptor-pointer tests. The current codec examples intentionally contain an invalid zero-role INPUT payload, so they do not resolve this.

4. **C12 / Medium — qualification fixtures leave important coverage/comparison choices open.** `qualification-fixtures.json:4` and all 24 text fixtures use only pseudo-random token IDs. The earlier requested plain language/code/numeral/repetition coverage was dropped, so the fixed suite does not exercise representative prompt structure or repeated-token recurrence. Media recipes (`:1130-1259`) have no declared comparison-position/checkpoint rule, while `implementation-contract.md:46-49` requires subgroup agreement over comparison positions. Add a few fixed semantic text recipes and repeated/alternating token fixtures, with disjoint calibration/holdout identities; tokenize/lock them before numerical qualification as already allowed for media. Freeze a deterministic media comparison rule and state checkpoints (e.g. all command positions, or an explicit fixed rule covering run boundaries and final positions). These are numerical-fidelity fixtures, not a demand for a downstream task benchmark. Preserve hard ceilings and update the fixed manifest deliberately.

5. **C13 / Low — implementation order still contradicts itself.** `plan.md:81` says start at U=8 and use U=1 where required, while `plan-gap-audit.md:179` says U=1 first, then qualified U=8. The normative contract is clear enough to resolve the choice, but the main plan still directs the implementer to the opposite starting milestone. Change the main text to U=1 first, U=8 after schedule/memory qualification; label later U=16 as an optional scale experiment. Avoid leaving conflicts to precedence prose.
