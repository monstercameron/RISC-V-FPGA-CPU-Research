# Start here

New to the project? Read the [README](README.md) first: it describes the three original RV64 cores, the current evidence and the commands. Then:

- [CPU quick start](cpu/README.md) and the [architecture contract](cpu/architecture.md);
- [the CPU tools index](sim/cpu/README.md), with `python -B sim/cpu/suite.py --list` as the single test and benchmark entry point;
- [DEVLOG.md](DEVLOG.md) for the latest work, and [AGENTS.md](AGENTS.md) for the rules every change follows.

The first experiment of October 2026, a PicoRV32 smoke simulation of third-party RTL, has its own guide in [sim/starter/START-HERE.md](sim/starter/START-HERE.md). Until November 2026 this file was a copy of that guide; its `.\run.ps1` and `bash run.sh` commands work only from `sim/starter/`.
