An original 64-bit RISC-V processor core

Atelier

Silicon, made in the open.

Atelier is a fully libre 64-bit RISC-V processor core: out-of-order, written in SystemVerilog, and developed in simulation against a sequential golden model. It is designed to compete with the best Arm cores per clock, on the workloads people run.

Evidence: simulation only

Current statusSource

What this is, and what it is not

Atelier is designed to compete with the best Arm cores. That is a design goal and a target we measure against, set per clock against an estimated Apple M6 reference. It is not a measured result.

Today it exists only in simulation. There is no silicon and no board result yet, and no hardware performance is claimed. Every number on this site comes from simulation of the design and says so.

Design goal

The per-clock goal is referenced to an Apple M6 estimate, bridged from laptop measurements. The reference is an estimate, not a measurement of an Apple M6, and the goal is a target, not a result.

Target documents: cpu/7zip-benchmark-targets.md and cpu/js-benchmark-targets.md.

Libre principles

  • RTL, tests, scripts and their licences are in the repository. Original work is MIT licensed (LICENSE).
  • Third-party licences and notices are kept apart, in licenses/.
  • Firmware is planned, not yet built. A hardware-specific licence has not been chosen.
  • Each result cites the run that produced it in the journal, so it can be reproduced.

Build and test

Nothing is downloaded and no FPGA is needed. From the repository root:

python -B sim/cpu/suite.py --list
python -B sim/cpu/suite.py unit --jobs 1
python -B sim/cpu/suite.py release-patch --dry-run
python -B scripts/check_repo.py

Roadmap

Each stage has exit evidence, listed in cpu/architecture.md section 6. No dates are given.

  • Plan C1: a real execution environment (traps, interrupts, counters, user mode).
  • Plan C2 to C4: scalar breadth, memory correctness, scalar floating point.
  • Plan C5 to C6: a complete vector engine and profile closure.
  • Plan C7: an FPGA proof on an exact part. No board run is claimed yet.

Target: RVA23U64, in stages. Not compliant today (cpu/architecture.md section 5).
