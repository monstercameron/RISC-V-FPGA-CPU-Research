The shape of a processor, one version at a time

An original 64-bit RISC-V core for FPGAs, built in public. Here its architecture is hung as a gallery: 66 drawings, from a core that fetched one instruction at a time to one that renames, reorders and retires thirty-two, and a notebook that keeps the dated record of how it got there.

II.

Le Journal

The development log as a catalogue: findings, timelines and commits by day, and a chart of simulated Dhrystone performance from 0.26 to 18.17 DMIPS/MHz. Beside it, a second measure: a scaled 7-Zip LZMA kernel, simulated at 9.41 / 3.29 MIPS/MHz compress / decompress on version 0.16.1 (64 KiB caches), against a goal of about 10.9 / 3.35; a laptop's Cortex-X925 runs the same scaled kernel natively at 8.34 / 2.59. On the full-size (d22) kernel the goal is about 2.03 / 2.18; in the deciding configuration version 0.15.4 reaches 1.53 / 1.98 in simulation with one miss at a time (75% / 91%), and version 0.16.0 with four misses in flight 2.19 / 2.32, the goal met in point estimate (108% / 107%). A third, a JavaScript interpreter, runs at 0.844x the laptop's rate per clock on version 0.17.0 in simulation (56.3% of a goal of 1.5x).

III.

The method

The target is RVA23U64, in stages. The current design implements RV64I with M, Zba, Zbb and Zbs, in three implementations of one contract; since 0.17.0 the out-of-order core can also be built with F and D (off by default). Results are simulated, labelled as such, and never presented as hardware.

Newest on the wall

No. 66, Les Lignes

Version 0.19.0, 22 novembre 2026. Data-cache lines of 16, 32 or 64 bytes, as an option; the default 8-byte line and its clocks are unchanged. On the candidate, Dhrystone runs 15,669 to 15,644 clocks at 64-byte lines (4 KiB caches, four misses in flight); with the 7-Zip d12 kernel at slow memory (MEM_LAT 350), decompression falls 2.2% and compression rises 0.65%, a regression not yet explained.
